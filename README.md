# Python Dictionaries

A comprehensive collection of Python dictionary operations, methods, and examples — perfect for learning and reference.

## 📖 Overview

This repository contains Jupyter Notebook (`.ipynb`) files demonstrating various Python dictionary concepts and methods. Whether you're a beginner learning Python or an experienced developer brushing up on dictionary operations, this collection serves as a practical guide.

## 📂 Contents

The notebook covers essential dictionary methods and operations, including:

- **Accessing values** — `dict.values()`
- **Accessing keys** — `dict.keys()`
- **Accessing items** — `dict.items()`
- **Adding/Updating entries** — `dict.update()`
- **Removing entries** — `dict.pop()`, `dict.popitem()`, `del`
- **Dictionary comprehensions**
- **Nested dictionaries**
- **Looping through dictionaries**

## 🚀 Getting Started

### Prerequisites

- Python 3.7+
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mwchuchu/python-dictionaries.git
   ```

2. Navigate to the project directory:
   ```bash
   cd python-dictionaries
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter PY0101EN-2-4-Dictionaries.ipynb
   ```
